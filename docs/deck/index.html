Platform Roles

Platform Roles

Four roles, one continuous loop from setup to structured data.

System Admin
Platform owner
Creates tenants, sets quotas, approves or rejects training requests.
Key outputGatekeeps platform spend and tenant provisioning.
Tenant Admin
Workspace owner
Defines entity types, uploads documents, assigns annotation tasks, submits training, promotes models.
Key outputOwns the workspace and drives the training lifecycle.
Annotator
Labeling
Works a task queue, labels entity spans, confirms completed documents.
Key outputBuilds the confirmed dataset the model trains on.
Business User
Day to day
Uploads documents, runs entity extraction, reviews results, queries and exports data.
Key outputTurns documents into structured, usable data day to day.
